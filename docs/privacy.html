Privacy policy

Last updated: 1 November 2026.

This policy covers the Strava Kudos browser extension, this website, and the maintainer-only Strava Kudos Publishing tool.

Browser extension

The extension reads the structure of the Strava page locally to find navigation, eligible kudos buttons, and indicators used to skip your own activities. It does not collect or transmit feed content to the project maintainer, store browsing history, or include analytics or advertising.

When you click Give Kudos to All, the extension clicks Strava's page controls. Strava then handles the resulting kudos requests through your existing signed-in session. These actions are visible to Strava and activity owners according to Strava's behavior and privacy policy. The extension does not read or store your Strava password or authentication tokens.

The displayed count is kept in the page while the extension is running and is not saved by the extension across page reloads. The extension does not sell data or send it to a separate project server.

Maintainer Google authorization

The publishing tool is being configured for the maintainer to authorize Chrome Web Store access. Extension users do not need to grant Google OAuth access to use the extension.

Publishing authorization uses the https://www.googleapis.com/auth/chromewebstore scope. The information handled for publishing includes the OAuth client credentials, refresh and access tokens, publisher and extension identifiers, extension packages, and API upload or review status responses. These are used only to authenticate and manage extension submissions.

Automated publishing is not yet implemented. When configured, publishing credentials must be kept in protected GitHub Actions environment secrets or secure maintainer storage, not in source code, public logs, or downloadable artifacts. Access tokens are short-lived; refresh tokens are retained while needed for publishing and should be removed when authorization is no longer needed.

Publishing requests go to Google's OAuth and Chrome Web Store services. If publishing runs in GitHub Actions, GitHub processes the credentials and packages needed for that job. These services apply their own policies: Google and GitHub. OAuth credentials are not sold, shared for advertising, or used to access unrelated Google services.

Revoking access

The maintainer can revoke the publishing tool's authorization from Google Account connections and remove retained credentials from GitHub secrets and local storage. Revocation prevents further authorized publishing until access is granted again.

This website and support

These pages contain no analytics, forms, external scripts, or tracking cookies added by this project. GitHub Pages hosts the site and may process technical request information, including IP addresses, under GitHub's privacy policy. Following external links is subject to the destination's policies.

Support is available through public GitHub issues. Information you post there is public; do not submit secrets or personal activity data. Contact the maintainer there for non-sensitive privacy questions.

Policy changes

This page will be updated when data handling changes, including when automated store publishing is implemented. Changes can be reviewed in the repository's history.
