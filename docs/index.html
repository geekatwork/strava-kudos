Strava Kudos

A lightweight, unofficial browser extension that adds a Give Kudos to All button to Strava navigation.

It clicks eligible kudos controls on activities already loaded on the page and displays a click count. It does not automatically scroll or load more activities. The count is not confirmation that every request succeeded.

Install from the Chrome Web Store · Source and development builds

Strava Kudos Publishing

Strava Kudos Publishing is a maintainer-only tool being configured to submit extension updates to the existing Chrome Web Store listing. Its Google OAuth authorization is for the maintainer's publishing account, not extension users.

The requested https://www.googleapis.com/auth/chromewebstore scope allows the tool to interact with the Chrome Web Store API. It is not used to read users' Gmail, Drive files, or Strava account credentials.

The repository currently tests and builds tagged releases. Automated store submission is planned and is not yet implemented. Store submissions remain subject to review.
